# Habitly

A tiny habit tracker used by map-it-all as its bundled demo project. The code is synthetic: it exists so the
map has something realistic to show (and a few things that are deliberately wrong).

- Auth lives in `server/legacy-auth.ts` (see the migration notes).
- The dashboard is `web/src/pages/Dashboard.tsx`; the old one was `web/src/old/Dashboard.tsx`.
- API docs: `docs/api.md`.
